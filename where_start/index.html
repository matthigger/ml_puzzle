Where Did It Start?

Practice site for the puzzle: try your estimate() on as many random earthquakes as you like.

Goal: land within 5 km of the epicenter in at least 90% of quakes, and as close as you can on average.

Each quake: 12 stations scattered over a 200 km by 200 km region record when the shock wave (6 km/s) reaches them; up to 3 clocks are off by seconds. estimate(stations, arrivals) gets the (12, 2) station positions (km) and the (12,) arrival times (s), and returns (x, y, t0). Everything runs here in your browser, and nothing leaves it unless you add a run to the leaderboard.

How your code is run
  • Type it here for one file of code, or Use my files to drop the .py / .ipynb files you work on elsewhere (or a .zip): the main file (the one defining estimate) can import the others. A notebook's code cells run top to bottom; lines starting with ! or % are skipped, and its own evaluate() calls run only 20 quakes, so loading stays quick.
  • Every function that takes (stations, arrivals) shows up in the Estimator menu, so you can compare a few in one go. Name a run to tell versions apart: each row keeps the code it ran.
  • Anything callable works, even a method of an object: 
    class Locator:
    def __init__(self, n_start=4):           # runs once, when your code loads
        self.n_start = n_start

    def estimate(self, stations, arrivals):  # runs once per quake
        ...

estimate = Locator(n_start=8).estimate

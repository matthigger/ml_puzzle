Ghost on the Circuit

Practice site for the puzzle: try your estimate() on as many random circuits as you like.

Goal: name the devices on the circuit, right in at least 95% of circuits, with as few watts off (averaged over many circuits) as you can.

estimate(x, y) gets x, the (72, 150) on / off log (1: device j on in hour t), and y, the meter's 72 hourly watts. It returns 150 watts, one per device: 0 (or under 1) for devices not on the circuit. A circuit is right when you name every device drawing 100 W or more, and none that isn't on it. Everything runs here in your browser, and nothing leaves it unless you add a run to the leaderboard.

How your code is run
  • Type it here for one file of code, or Use my files to drop the .py / .ipynb files you work on elsewhere (or a .zip): the main file (the one defining estimate) can import the others. A notebook's code cells run top to bottom; lines starting with ! or % are skipped, and its own evaluate() calls run only 20 circuits, so loading stays quick.
  • Every function that takes (x, y) shows up in the Estimator menu, so you can compare a few in one go. Name a run to tell versions apart: each row keeps the code it ran.
  • Your estimator runs once per circuit: keep it under a second or so.
  • Anything callable works, even a method of an object: 
    class Fitter:
    def __init__(self, n_top=8):   # runs once, when your code loads
        self.n_top = n_top

    def estimate(self, x, y):      # runs once per circuit
        ...

estimate = Fitter(n_top=6).estimate

Slice Crawl

Practice site for the puzzle: try your estimate() on as many random crawls as you like.

Goal: name the true best of the pizza shops in at least 95% of crawls, tasting as few slices (averaged over many crawls) as you can.

crawl.taste(i) buys a slice from shop i and returns its rating; estimate(crawl) returns the shop you believe is best. Everything runs here in your browser, and nothing leaves it unless you post to the leaderboard.

How your code is run
  • Paste your code, or open your .py or .ipynb. A notebook's code cells run top to bottom; lines starting with ! or % are skipped, and its own evaluate() calls run only 50 crawls, so loading stays quick. Add any .py helper files it imports.
  • Every function that takes a crawl shows up in the Estimator menu, so you can compare a few in one go. The leaderboard always uses estimate.
  • Anything callable works, even a method of an object: 
    class Racer:
    def __init__(self, z=2):    # runs once, when your code loads
        self.z = z

    def estimate(self, crawl):  # runs once per crawl
        ...

estimate = Racer(z=2.5).estimate
